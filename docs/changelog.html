Changelog

Release history for nexa (nexa-ui on PyPI) and its vendored C99 CUI core.

v1.4.0 Latest · CUI 1.4 Sync

  • Instrument cluster: Added ui.knob, ui.fader, ui.level_meter, ui.radial_gauge, ui.readout, ui.dot_display, ui.dot_chart, and ui.event_track — every one returns the value the user dialed in.
  • Text, media & files: Right-to-left layout and text (direction=ui.TextDirection.RTL), embedded emoji with ui.emoji_picker and color-emoji font loading, a scrollback-backed ui.terminal via ui.TerminalBuffer, ui.file_browser / ui.file_picker for real directories (with an in-tree ui.fs_list), ui.image_viewer, and ui.cropper.
  • Charts & calendars: ui.candlestick for OHLC data plus annotations= on every chart (ui.ChartAnnotation), ui.month_calendar with events, and ui.tour guided app walks.
  • Developer tools (CUI 1.3): ui.problems, ui.pipeline, ui.trace_view, ui.waterfall, ui.graph_view, ui.commit_graph, ui.keymap, ui.test_explorer, ui.stack_trace, ui.blame, ui.coverage, ui.regex_tester, ui.request_bar, ui.api_explorer, ui.feature_flags, ui.uptime_bars, ui.time_histogram, ui.kv_editor, ui.query_builder, and ui.schedule_picker — data in as plain dicts, results out as named tuples.
  • Context-free utilities: ui.regex_search (CUI's RE2-style engine with named groups), ui.cron_next / ui.cron_describe, ui.url_params / ui.url_set_params, ui.http_reason / ui.http_method_name, plus ui.UI.request_wakeup, set_strings/get_strings, response_status, and is_software.
  • Engine re-sync & ABI hardening: csrc/ moved to CUI v1.4.0 (434 → 501 public functions, 208 → 304 structs); tools/gen_abi.py regenerates the ctypes mirrors from cui.h and an audit proves every mirrored struct matches the compiler's sizeof/offsets; tools/gen_devtools_bridge.py generates the struct-returning bridges so ctypes never passes a struct by value.

v1.1.0 CUI 1.1 Sync

  • Multi-split Docking Workspaces: Added ui.dockspace, ui.dock_panel, ui.dock_save, and ui.dock_load with interactive tab dragging, split previews, and layout serialization.
  • Tree Table & Editable Path Bar: Added virtualized multi-column ui.tree_table + ui.tree_sort and breadcrumb/editable ui.path_bar + ui.path_bar_menu.
  • Rich Markdown, Source Code Editor & Diff Viewer: Added CommonMark/GFM ui.markdown (with interactive task checkboxes and ui.markdown_apply_task), multi-line syntax-highlighted ui.code_editor, and side-by-side/inline ui.diff_view + headless ui.diff_compute & ui.diff_words.
  • Systems & Creative Studio Widgets: Added binary ui.hex_view, profiler ui.flame_graph + ui.flame_sort, Bezier ui.curve_editor + ui.curve_eval, perceptual OKLab ui.gradient_editor + ui.gradient_eval, and multi-track ui.timeline_editor.
  • PyPI Distribution & Complete Exports: Published as pip install nexa-ui with 505 typed top-level exports in nexa.__all__, cross-platform wheel builds, and optional --rtl BiDi + Arabic shaping.

v1.0.0

  • Initial C99 + Python zero-dependency architecture covering 150+ immediate-mode components, OpenGL 3.3 + multi-threaded SIMD software renderer, Functional/Procedural/OOP paradigms, 8 OKLCH accents, and GIL-free BackgroundRunner / asyncio integration.
