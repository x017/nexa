nexa Documentation Wiki

Central knowledge base for nexa (pip install nexa-ui, imported as import nexa as ui)—a zero-dependency Python port of CUI with 160+ native C99 desktop components, OpenGL 3.3 + multi-threaded SIMD software rendering, and 0% idle CPU.

bash · install & verify
pip install nexa-ui
python3 -c "import nexa as ui; print(ui.__version__)"

Important: Always install nexa-ui from PyPI (pip install nexa-ui or uv add nexa-ui), not the unrelated nexa package, and avoid naming a local file nexa.py or folder nexa/.
